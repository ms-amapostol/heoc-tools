# HEOC Tools

Free planning tools for universities, community colleges, K-12, EdTech companies and education nonprofits, built by [Higher Ed Ops Consulting](https://higheredopsconsulting.com).

| Tool | What it does |
|---|---|
| [AI Readiness Check](https://ms-amapostol.github.io/heoc-tools/ai-readiness-check/) | 18-question self-assessment with a readiness score and a 90-day plan |
| [Automation Opportunity Finder](https://ms-amapostol.github.io/heoc-tools/automation-opportunity-finder/) | Ranks repetitive tasks by hours saved and ease of automation |

Each tool is a single HTML file. Nothing a user enters leaves their browser. Sample data is fictional.

These tools give general planning guidance only. They are not legal, compliance, privacy, financial or professional advice.
